# HRIS Data Quality & Governance Intelligence

Interactive portfolio prototype demonstrating rule-oriented employee master-data quality monitoring, exception classification, remediation tracking, and CSV export.

## Contents
- `index.html` — standalone interactive dashboard. Open locally in a modern browser or publish with GitHub Pages.
- `Case_Study.docx` — project case study covering the business problem, methodology, governance framework, limitations, and interview talking points.

## How to publish inside the portfolio repository
1. In the `celinechan-portfolio` repository, create the folder path `projects/hris-data-quality/`.
2. Upload all three files into that folder.
3. Once committed, the demo should be available at:
   `https://siongleen-pixel.github.io/celinechan-portfolio/projects/hris-data-quality/`

## Important scope and limitations
- All employee records are synthetic and created for demonstration.
- The dashboard is a standalone HTML/CSS/JavaScript prototype; it is not connected to a production HRIS or database.
- Remediation edits are held in browser-session memory only and are not persisted.
- The quality indicator is illustrative, not a validated enterprise metric.
- No AI/ML model, automated correction, authentication, role-based access, or production audit trail is implemented.
- Validation rules and severity labels are illustrative and must be approved against an organisation's data dictionary, policies, and control requirements before operational use.

## Suggested portfolio description
Built an interactive HRIS data-quality prototype using synthetic data to demonstrate employee master-data validation, exception prioritisation, remediation tracking, and governance-oriented reporting.
