# Celine Chan — HR Technology & Transformation Portfolio

This is a static, responsive portfolio website built with plain HTML and CSS. It is suitable for GitHub Pages and does not require a build system.

## Files
- `index.html` — complete website
- `README.md` — publishing instructions

## Publish free with GitHub Pages

1. Sign in to https://github.com or create a free account.
2. Create a **public** repository named `celine-chan-portfolio` (or another name you prefer).
3. Open the repository, choose **Add file → Upload files**, and upload `index.html` and `README.md`.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main`, folder `/(root)`, then click **Save**.
8. Wait for the deployment to finish. Your site will normally be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/celine-chan-portfolio/`
9. Return to **Settings → Pages** and click **Visit site** to confirm the exact URL.

GitHub Pages on GitHub Free requires a public repository. The published website is publicly accessible. Do not upload confidential employer/client information, personal identification numbers, private HR data, API keys or passwords.

## Before publishing
- Review the wording and confirm all career metrics are accurate and approved for public use.
- Add links to live demos only when they are ready and tested.
- If you prefer not to publish the repository publicly, choose a different hosting option and review its current free-tier terms.

## LinkedIn
After the site is live:
1. Open your LinkedIn profile.
2. Add the URL under **Featured → Add → Add a link**.
3. Use the title: `View My Portfolio | HR Technology & Digital Transformation`.
4. Also add it under **Contact info → Website** if desired.
